# ☕ Get Me A Chai

Get Me A Chai is a crowdfunding and creator-support platform where users can support their favorite creators by contributing small donations. Inspired by platforms like Buy Me a Coffee, it provides a simple way for creators to receive support from their audience.

## 🚀 Features

- Creator profile pages
- Support creators with donations
- Secure payment integration
- Personalized messages with contributions
- User authentication
- Responsive design
- Dashboard for creators

## 🛠️ Tech Stack

- Next.js
- React.js
- Tailwind CSS
- MongoDB
- NextAuth.js
- Razorpay / Payment Gateway
